ABSuite · the interface

The Trust Operations Center.

A room you enter, not a dashboard you scroll.

A glass cube whose eight corners are the architectural layers, orbited by the seven operations the system performs every second it runs. It is not a mock-up: it reads five services over HTTP and a socket, and shows UNKNOWN for every figure it cannot reach.

[ The rule the room lives by ]

The core always shows the strongest claim the system can presently defend. Nothing else changes colour.

DARKNothing has been checked. An empty instance shows an empty core.
TURQUOISEA verification is in flight, right now.
GREENThe chain verified. Content, linkage and signatures.
REDSomething failed. The room names the record that broke.

Every perpetual animation in the interface is bound to a stated condition, and check:motion-is-evidence fails the build if one is not. Motion here is a claim about the world, so a thing that moves forever while nothing is happening is a lie told at sixty frames a second.

[ The seven operations, in orbit ]

  1. 1ObserveCapture every action — the subject, the authority it held, and hashes of what it processed.
  2. 2VerifyProve integrity cryptographically. Checkable by someone holding only a public key.
  3. 3ExplainTurn a record into plain language derived from signed fields, every sentence naming its source.
  4. 4GovernWhich rule permitted this, and — when the rule demanded a person — whether one answered.
  5. 5ArbitrateResolve disagreement with stated evidence weight, and say plainly when consensus was not reached.
  6. 6ActExecute only under a capability that was actually granted.
  7. 7LearnMeasure the system against itself. Every number came from a benchmark on a stated machine.

[ What you can open ]

IdentityWho is acting, and can they prove it. Enrolment, proof of possession, suspension with a stated reason.
ApprovalsWhat is waiting on a person. Each request bound to a hash of exactly what will run.
WatchWhat has been raised — and how much of the record that answer covers.
Unknown queueWhat cannot yet be shown, each with the step that would settle it.
ReplayWhat happened, in the order it happened, compared against the recorded hashes.
PoliciesThe rules, what is owed, and the refusals held in place by tests.

[ Run it yourself ]

All five services and the interface, in one command. It waits until each part answers rather than guessing at a delay, and tells you what did not come up.

pnpm install && pnpm build && pnpm room

Then press / for the command palette. A published copy of this interface with no backend can never be live — there is nothing on the far side to answer it, and the room says so in those words rather than showing invented numbers.
