# Working notes

These are **not project documentation**. They are dated working notes — strategy
memos, market reads, point-in-time reviews — kept in the open because the
reasoning behind a decision is worth more than the decision alone, and deleting
them would leave the *what* without the *why*.

Read them as one person's analysis on a given day, not as claims the project
makes. Where they disagree with the code, the code is right. Where they quote a
number, check it against `pnpm test` rather than the page.

Several carry a **Historical** banner because they have been overtaken by
events. That is the point of keeping them.

## On the competitor notes

Some of these compare ABSuite to named products. Those comparisons were made
against public documentation on the date at the top of each file, by someone
with an obvious interest in the answer. They are not neutral, they go stale, and
they should not be cited as fact by anyone — including this project.

If you maintain one of the products named here and something is wrong, an issue
gets it corrected.
